## 🚀 Nedir?

SELF-AI, yapay zekâ dünyasına adım atan herkes için tasarlanmış bir başlangıç kitidir. Hem öğrenme hem de arşivleme aracı olarak kullanabilirsiniz:

- Yapay zekâ kavramlarını öğrenmek için hazır bir yol haritası
- AI araçlarını, repoları ve kursları kişisel arşivinizde toplamak
- Sözlük ile temel kavramlara hızlıca başvurmak
- 170+ araç ve kaynak kartına hazır erişim

## 💻 Kurulum

Node.js (v18+) gereklidir.

```bash
# Repoyu klonla
git clone https://github.com/KULLANICI_ADI/SELF-AI.git

# Klasöre gir
cd SELF-AI

# Bağımlılıkları yükle
npm install

# Çalıştır
npm start
```

Tarayıcıda `http://localhost:3000` adresini aç.

---

## ✏️ Kendi Arşivini Oluştur

Uygulama içindeki **+ Add (Ekle)** butonu ile yeni araç ve kaynak ekleyebilirsin.

Toplu ekleme yapmak istiyorsan `src/self-ai_data.json` dosyasını düzenleyebilirsin.
